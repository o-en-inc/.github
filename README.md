# 株式会社オーエン

株式会社オーエンの公式GitHub Organizationです。

当Organizationでは、当社が開発・管理するソフトウェア、ライブラリ、開発ツールなどのリポジトリを管理しています。

## リポジトリについて

公開リポジトリは、各リポジトリに記載されたライセンスおよび利用条件に従ってご利用ください。

非公開リポジトリは、当社が許可したメンバーのみアクセスできます。
